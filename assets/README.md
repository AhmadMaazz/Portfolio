# assets/

- **`resume.pdf`** — linked from the "Download CV" button in the hero section.
- **`photo.jpg`** — used in the hero portrait (`.hero-photo` in `index.html`). It's
  displayed large, grayscale-treated, with edges fading into the page background
  and a soft accent-colored glow behind it (see `.hero-photo` in `css/styles.css`).

To swap either file, just replace it here with a new file of the same name —
no code changes needed.
